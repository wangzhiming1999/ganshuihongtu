# 赣水红途 · 江西红色旅游文化平台

江西红色文化宣传网站。讲好中国共产党在江西的革命故事——井冈山精神、苏区精神、长征精神。

> 没有商品，没有门票。我们只想把家乡的红色故事，讲给更多人听。

**在线访问**：https://ganshuihongtu.app.workbuddy.host/

## 运行方式

双击 `index.html` 直接在浏览器打开即可（纯静态，零依赖零构建）。

本地服务器预览（推荐）：

```
cd ganshuihongtu-webpage
python -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 技术说明

- **纯静态**：HTML + CSS + 原生 JS，无框架依赖，零构建
- **主题色**：中国红 `#C8102E` + 深红 `#8C0F0D` + 暖白 `#FAF7F2` + 金色点缀 `#FFD9A0`
- **动效**：
  - 进场 fade-up + 交错延迟（IntersectionObserver）
  - 数字滚动（data-count）
  - 首页 Hero Canvas 粒子「灰飞烟灭」余烬飘散（respects `prefers-reduced-motion`）
  - 页眉背景视差滚动 + 图片揭示动效
- **图片**：`assets/` 下 AI 生成实景图（历史考据向），本地引用
- **响应式**：1000px / 600px 两档断点，移动端自适应

## 二次开发

- 故事详情页由 `assets/_gen_stories.py` 批量生成：在 `STORIES` 列表中增删故事后运行 `python _gen_stories.py`，即可重新产出全部 `story-*.html`
- 样式体系集中在 `assets/style.css`（共享设计系统）与 `assets/story.css`（故事页组件）
- 欢迎 Fork 后为自己的家乡定制一套「红途」——替换图片与文案即可

## 内容考据
