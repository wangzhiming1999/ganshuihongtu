# 赣水红途 · 江西红色旅游文化平台

纯公益、非商业的江西红色文化宣传网站。讲好中国共产党在江西的革命故事——井冈山精神、苏区精神、长征精神。

> 没有商品，没有门票。我们只想把家乡的红色故事，讲给更多人听。

## 站点结构（17 页）

| 页面 | 说明 |
|---|---|
| `index.html` | 首页：杂志式排版、四大圣地、故事精选、研学、公益宣言 |
| `jinggangshan.html` | 井冈山：历史时间轴 + 景点详解 + 井冈山精神 |
| `ruijin.html` | 瑞金：红色故都，苏维埃共和国从这里走来 |
| `nanchang.html` | 南昌：军旗升起的地方，八一起义全程时间轴 |
| `yudu.html` | 于都：长征第一渡，夜渡时间轴 + 大数字带 |
| `stories.html` | 红色故事馆：10 个故事的吸引力封面列表 |
| `story-01.html` ~ `story-10.html` | 每个故事的独立详情页：悬念开篇、完整叙事、人物档案、历史背景、精神内核、相关地点 |
| `edu.html` | 红色研学：4 项公益项目 + 报名流程 |

## 运行方式

双击 `index.html` 直接在浏览器打开即可（纯静态，零依赖零构建）。

本地服务器预览（推荐）：

```
cd ganshuihongtu-webpage
python -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 技术说明

- **纯静态**：HTML + CSS + 原生 JS，无框架依赖
- **主题色**：中国红 `#C8102E` + 深红 `#8C0F0D` + 暖白 `#FAF7F2` + 金色点缀 `#FFD9A0`
- **动效**：
  - 进场 fade-up + 交错延迟（IntersectionObserver）
  - 数字滚动（132 红色遗址 / 11 革命场馆 / 58 研学课程）
  - 首页 Hero Canvas 粒子「灰飞烟灭」余烬飘散（respects `prefers-reduced-motion`）
  - 页眉背景视差滚动 + 图片揭示动效
- **图片**：`assets/` 下 11 张 AI 生成实景图（历史考据向），本地引用
- **响应式**：1000px / 600px 两档断点，移动端自适应

## 内容考据

历史事件、时间、人物、数字均依据公开史料整理（如《中国共产党历史》、地方志、纪念馆展陈资料），部分细节存在民间口述版本差异时，采用流传最广的版本。平台为非营利公益项目，内容免费开放，欢迎指正补充。
